# Bitwise Operators (Java)

## Description
A simple Java program demonstrating bitwise operators.

## Features
- Bitwise AND (&)
- Bitwise OR (|)
- Bitwise XOR (^)
- Left Shift (<<)
- Right Shift (>>)

## Technology Used
- Java
- Operators

## Output
AND: 2
OR: 7
XOR: 5
Left Shift: 20
Right Shift: 2
